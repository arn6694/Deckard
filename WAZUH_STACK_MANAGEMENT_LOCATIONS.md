# Finding Stack Management in Wazuh Dashboard

## Location Options

### Option 1: Menu Approach (Most Reliable)
1. Click the **Menu icon** (☰) in top-left
2. Look for: **Management**
3. Under Management, look for:
   - **Stack Management** or
   - **Saved Objects** or
   - **Dashboards**

### Option 2: Direct URL
If you can't find it in menus, try the direct URL:
```
https://10.10.10.40/app/management
```

Or try:
```
https://10.10.10.40/app/dashboards
```

### Option 3: Look in Left Sidebar
In the left sidebar, you might see:
- **Dashboards** (click here to import)
- **Visualizations**
- **Discover**
- **Dev Tools**
- **Management** (with dropdown)

### Option 4: Alternative Import Path
1. Go to: **Dashboards**
2. Click: **Create New Dashboard** or **Import**
3. Should see import option there

---

## What You're Looking For

**Import functionality** could be under:
- Stack Management → Saved Objects → Import
- Management → Saved Objects → Import
- Dashboards → Import
- Settings → Import
- Advanced → Import

---

## Quick Navigation

Once logged in at https://10.10.10.40:

1. **Top Left**: Look for menu/hamburger icon (☰)
2. **Click**: Opens navigation menu
3. **Find**: "Management" or "Settings"
4. **Click**: Opens management options
5. **Look for**: "Saved Objects" or "Import/Export"

---

## If You Find Import

Once you find Import:
1. Click: **Import**
2. Select: `docs/wazuh-threat-intelligence-dashboard.json`
3. Click: **Import** or **Upload**
4. Confirm: Dashboard objects will be imported
